## Version anglaise (recommandée sur Upwork)

**Project title** (max. 70 caractères)
Le Baobab: 3D Restaurant Website with AI-Generated Dish Models

**Your role**
Web designer & front-end developer

**Project description**
Concept project: a 4-page website for an Ivorian restaurant in Abidjan, built from a real client-style brief (home, menu, about, contact).

The challenge: make the menu irresistible without a 3D studio. I turned the restaurant's own photos into interactive 3D. Each image is cut out with an AI model (BiRefNet), given depth with Depth Anything V2, then rendered in Three.js: dishes assemble from gaussian splats, then become a lit relief surface that rotates with the mouse or finger.

What I delivered:
- 16 dishes and drinks in 3D, driven by a JSON file the owner can edit without touching code
- Scroll storytelling with GSAP ScrollTrigger: pinned signature dishes, snapping, animated headlines
- Keyword chatbot answering 18 question types (hours, prices, delivery, payment) that pre-fills the booking form
- Validated reservation form (Formspree or WhatsApp), Google Maps, WhatsApp button
- Mobile-first, accessible, prices in FCFA
- Lighthouse mobile on the live site: 98–99 performance, 100 accessibility, 100 SEO

Stack: HTML, CSS, vanilla JavaScript, Three.js, GSAP, Transformers.js (local AI), GitHub Pages.

**Skills** (Upwork en propose jusqu'à 5)
Three.js · GSAP · JavaScript · Web Design · Responsive Design

## Version française

**Titre**
Le Baobab : site 3D pour un restaurant, plats modélisés par IA

**Rôle**
Web designer et développeur front-end

**Description**
Projet conceptuel : site de 4 pages pour un restaurant ivoirien à Abidjan, réalisé à partir d'un cahier des charges de type client (accueil, menu, à propos, contact).

Le défi : rendre le menu irrésistible sans studio 3D. J'ai transformé les photos du restaurant en 3D interactive. Chaque image est détourée par IA (BiRefNet), reçoit une profondeur avec Depth Anything V2, puis est rendue avec Three.js : le plat se forme à partir de « gaussian splats », puis devient une surface en relief éclairée qui pivote à la souris ou au doigt.

Livré :
- 16 plats et boissons en 3D, pilotés par un fichier JSON modifiable sans toucher au code
- Récit au défilement avec GSAP ScrollTrigger : plats phares épinglés, aimantation, titres animés
- Chatbot par mots-clés (18 types de questions : horaires, prix, livraison, paiement) qui pré-remplit la réservation
- Formulaire de réservation validé (Formspree ou WhatsApp), Google Maps, bouton WhatsApp
- Mobile d'abord, accessible, prix en FCFA
- Lighthouse mobile sur le site en ligne : 98–99 en performance, 100 en accessibilité, 100 en SEO

Outils : HTML, CSS, JavaScript sans framework, Three.js, GSAP, Transformers.js (IA locale), GitHub Pages.
